A one-line entry for the make.fun bounty **"The 3AM Fridge Text"** — a text message someone sends to their fridge at 3AM.

## The line

> i'm standing here in my underwear eating your pickles straight from the jar and i need you to know this is YOUR fault.

## Run it

```bash
python3 main.py
```

It prints exactly the one line above.
